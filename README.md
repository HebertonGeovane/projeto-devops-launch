# 🚀 Projeto DevOps Launch

Bem-vindo ao  Projeto DevOps Launch.

Neste projeto você irá aprender, de forma prática, como preparar uma aplicação para publicação na nuvem utilizando ferramentas muito utilizadas no mercado.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura do projeto

```text
projeto-devops-launch/
│
├── website/
│   ├── css/
│   ├── js/
│   ├── index.html
│   └── metadata.json
├── deploy.sh
├── README.md
└── .gitignore
```

## Objetivo desta atividade

Nesta primeira etapa você irá:

- Clonar o repositório
- Abrir o projeto no Visual Studio Code
- Executar a aplicação com o Live Server
- Conhecer a estrutura do projeto
- Fazer pequenas alterações no código
- Criar um commit
- Enviar suas alterações para o GitHub

Nas próximas atividades iremos evoluir este projeto utilizando Docker, Amazon ECR e Amazon EC2.

Bons estudos!
