PRÁTICA DEVOPS • PROJETO 01

Da aplicação local ao deploy na AWS.

Uma experiência prática para aprender como construir, empacotar e publicar uma aplicação utilizando HTML, CSS, JavaScript, Docker, Amazon ECR e Amazon EC2.

Explorar arquitetura

ARQUITETURA DO DEPLOY

Um fluxo simples, visual e profissional

O projeto começa no computador do aluno, passa pela criação da imagem Docker, segue para o Amazon ECR e termina com a execução do container em uma instância Amazon EC2.

1

Desenvolvimento da página com HTML, CSS e JavaScript.

2

Build da imagem utilizando um Dockerfile.

3

Push da imagem para o repositório Amazon ECR.

4

Deploy do container em uma instância Amazon EC2.
